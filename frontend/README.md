# React dashboard — v1.2.0-rc1

Основная вкладка — **Прогоночное тестирование**.

Функции:

- REGGO ONVIF/RTSP;
- PTZ/zoom и звук камеры;
- локальный YOLO на Acer;
- схема шасси с моделью `1 TB6612 = 1 борт`;
- RAW PWM и отдельный тест левого/правого борта;
- подсветка GPIO;
- дальномеры;
- профили ходовой;
- голос, Hermes и автономный агент;
- SQLite-логи.

Для просмотра дизайна без железа:

```text
http://127.0.0.1:5173/?demo=1
```

Сборка из lock-файла:

```bash
npm ci
npm run build
```
