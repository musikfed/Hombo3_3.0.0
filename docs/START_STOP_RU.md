# Hombo3 — запуск и безопасная остановка (Linux / Windows)

В Hombo3 уже есть проверенные стартеры `START_HOMBO3_LINUX.sh`,
`START_HOMBOWIFI_LINUX.sh`, `START_HOMBO3.cmd` и
`START_HOMBOWIFI.cmd`. **Они сохранены без изменений.** Новые
`start.sh` и `start.ps1` переиспользуют существующие Linux/Windows
команды, не подменяя настройки ESP32, камеры или web-панели.

## Linux

В каталоге этого репозитория после `SETUP_LINUX.sh`:

```bash
bash start.sh        # запустить управление роботом, терминал занят сервером
bash stop.sh         # в ДРУГОМ терминале: сначала STOP моторов ESP32
```

## Windows PowerShell

После `SETUP.cmd`:

```powershell
.\start.ps1         # сервер управления, работает пока открыта консоль
.\stop.ps1          # из второго окна PowerShell
```

Сервер по текущим настройкам слушает `8088`, но скрипт читает
**реальный `settings.app_port`**, а не прошивает порт в коде.

**ВАЖНО ДЛЯ РОБОТА:** команда завершения сперва отправляет
`POST http://127.0.0.1:<порт>/api/stop` с `{"voice":false}`.
Она ждёт успешного ответа от ESP32 через backend. Только после ответа
отправляет сигнал остановки **процессу backend этого конкретного
checkout**, а не всем Python-процессам. Если команда остановки
двигателей недоступна (нет сети, ошибка ESP32), сервер остаётся
работать: сначала останови робота физически. Скрипты не отключают
питание, не прошивают ESP32 и не управляют камерой T23N или YadroKreator.

**Веб-интерфейс робота** — FastAPI/React Control Center на локальном
адресе Hombo3, не интерфейс PegineLab WIFICAM на камере `:8090`
и не фабрика прошивок на Huananzhi `:62404`.
