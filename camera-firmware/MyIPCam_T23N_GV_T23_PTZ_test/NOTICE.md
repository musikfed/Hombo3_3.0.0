# Notice

This test branch does not redistribute the donor Thingino firmware image, kernel, proprietary sensor/ISP components, or a prebuilt SD image.

The build script expects the user to build or otherwise obtain their own compatible Thingino output and verifies the exact known-good donor image SHA-256 used during this hardware experiment.

MyIPCam Stage2 is currently an experimental integration layer: custom MyIPCam web UI + test build scripts on top of already proven T23/T23N kernel/drivers/services. It is not yet the final independent minimal MyIPCam OS.
