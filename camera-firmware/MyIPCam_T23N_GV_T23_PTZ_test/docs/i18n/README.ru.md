# MyIPCam OS 3.1

Русское описание тестовой ветки проекта MyIPCam для платы GV-T23-PTZ-MAIN-V2.0 и процессора Ingenic T23/T23N.

Ветка предназначена для проверки загрузки системы с microSD, работы Wi-Fi, аппаратного H.264 и PTZ. Это не финальная версия MyIPCam OS.

Проверенная конфигурация: SC2336, AltoBeam ATBM6012BX, ULN2803LV, microSD 1-bit MMC.

Ключевые слова для поиска: MyIPCam, T23, T23N, IP-камера, microSD boot, SC2336, ATBM6012BX, PTZ, локальная камера.
