# MyIPCam OS 3.1

Ово је тестна хардверска грана MyIPCam за плочу GV-T23-PTZ-MAIN-V2.0 и Ingenic T23/T23N.

Грана служи за проверу boot-а са microSD, Wi-Fi везе, хардверског H.264 и PTZ. Није финална верзија MyIPCam OS.

Проверена конфигурација: SC2336, AltoBeam ATBM6012BX, ULN2803LV и 1-bit MMC microSD.
